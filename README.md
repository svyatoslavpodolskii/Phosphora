# Phosphored

Local-first PWA: одна карта заметок, людей, проектов и задач. Svelte + TypeScript + Vite. Данные — SQLite WASM в Worker, официальный OPFS SAH pool VFS. Без аккаунта и сервера данных.

## Запуск

Требуется Node.js 22. На Windows используйте `npm.cmd`, если PowerShell блокирует `npm.ps1`.

```sh
npm install
npm run dev
```

Dev: http://127.0.0.1:5173. Для проверки PWA и offline используйте production-сборку:

```sh
npm run build
npm run preview
```

PWA: http://127.0.0.1:4173. Для внешнего хостинга нужен HTTPS. Публикуется только `dist/`. Не меняйте origin, если хотите продолжать пользоваться той же локальной базой. Установка доступна через браузер или меню приложения, когда браузер предоставляет install prompt.

## Возможности

- Независимые хранилища: создание, переименование, переключение и восстановление последнего открытого.
- Просторный Markdown-редактор, быстрые ссылки, форматирование и контекстное создание.
- Импорт папки или ZIP Obsidian с подпапками и вложениями; обратный экспорт Markdown.
- Пять тем оформления и импорт пользовательских тем; несколько характеров физики.
- Поиск по названию, тексту, алиасам, типу, свойствам и ближайшим связанным сущностям.
- Линзы «Сейчас / Всё / Архив», независимые состояния и оформление.
- Pan, zoom, pinch, drag в зоны состояний, клавиатурные команды, кластеры и сокращение избыточных связей.
- Транзакционные миграции, защита устаревших изменений, блокировка второй вкладки, запрос persistent storage.
- Экспорт/импорт карты JSON, выгрузка SQLite, локальные снимки перед импортом и удалением через интерфейс.
- Plugin API без зависимости от Svelte, встроенные шаблоны и пять providers карты, установка пакетов .phosphored с разрешениями и изоляцией.

Изменения в редакторе сохраняются кнопкой или Ctrl/⌘ + Enter. При закрытии изменённого редактора показывается выбор сохранения. Удаление в UI требует подтверждения. Архивирование не удаляет связи.

## Проверки

```sh
npm run check
npm test
npx playwright install chromium
npm run build
npm run test:e2e
```

Для benchmark запустите dev-сервер, затем `node scripts/benchmark.mjs`. Результат — `artifacts/graph-benchmark.json`.
