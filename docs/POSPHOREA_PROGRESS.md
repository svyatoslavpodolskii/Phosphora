# Posphorea — текущая итерация

Исходное задание: [POSPHOREA_OBJECTIVE.md](POSPHOREA_OBJECTIVE.md). Этот файл описывает новый этап; исторические отчёты не являются доказательством соответствия новым требованиям.

## Сохранённая архитектура

Svelte 5, SQLite WASM/OPFS, PixiJS с Canvas fallback, единые Atom/Link, публичный Plugin API и существующая система раскладок сохранены. Репозиторий и GitHub Pages URL остаются прежними. Форматы `phosphored-*`, YAML-поля, адреса OPFS, namespace настроек и пользовательские ID не переименовываются. Новые экспорты используют Posphorea, импорт принимает прежние расширения.

## Реализовано в коде

- Posphorea в UI/title/manifest, документации, названиях пакета и новых экспортируемых файлах.
- Living drag: расчёт соседей при начале жеста; затухание по графу, физической дистанции и нагрузке ветви; pins блокируют распространение; ограниченный набор реакции; полное восстановление вовлечённых координат при отмене; текущая геометрия передаётся provider при смене режима.
- Связь переносом на атом с задержкой и явным preview, защита от дублей, восстановление композиции. Существующие handles reconnect/delete сохранены. Undo ограничен по времени и отделён от camera transforms.
- «Поле / Канбан» доступны напрямую; «Поле / Сейчас / Архив» остаются состояниями одной базы. «Отложить» — вторичное действие; тип доступен возле основных свойств; старые task-атомы сохраняются, новый тип Task не предлагается.
- Отдельные обычные checkbox и `#task` checkbox; Kanban собирает явные задачи и сохранённые legacy-задачи, группирует по исходной заметке, сохраняет историю и синхронизирует текст.
- Общие монохромные SVG/Canvas/GPU-знаки; пользовательские и старые glyph-иконки остаются допустимыми.
- Контрастные и мягкие темы; static/world/parallax фон с ограниченным набором фигур и учётом reduced motion.
- Опциональный Folders plugin: lasso selection, именованные области в том же мире, нормализованные пересекающиеся membership, наследование контекстных потомков и навигационная полоса. Отключение убирает представление, сохраняя данные.
- Визуальный редактор развивается поверх Markdown; непредставимая разметка должна сохраняться исходными блоками, без скрытой потери данных.

## Проверки и ограничения

Целевые тесты охватывают геометрию drag/cancel, pins, смену provider, explicit tasks, совместимость metadata, Undo, темы и Folders. Замеры cached drag выполняются на 100/500/1000 атомах; это не замена браузерной проверке всех новых функций на каждом размере.

До объявления полного Definition of Done остаются: полный проход по мобильному UX и экспортам, физические Android/iOS устройства, визуальная проверка плотных движущихся графов 1000 атомов и всех provider, полная миграция старых e2e на визуальный редактор, работа Folders при удалении заметки-владельца определения и workflow rename/remove, дальнейшая унификация Tasks/Kanban через публичные plugin surfaces. Проверки сборки и тестов фиксируются в commit/отчёте конкретного этапа.

## Будущий Intelligence plugin

После fundamentals: общий provider contract для OpenRouter, OpenAI-compatible endpoints и локальных моделей с ключами пользователя. Предложения links/folders/types, поиск дублей, merge, hub и bridge Atom требуют preview + accept/reject. AI не меняет структуру молча. Платные вызовы и реализация AI сейчас не требуются.
