# Камера, внимание и организация — состояние проверки

Требования: attachment `3586b950-777b-49bf-9454-f6d604d8a216/Вставленный текст.txt`.

## Изменения

- Pinch задаёт абсолютный transform по исходной world-точке, расстоянию и текущему midpoint. Исправлен двойной учёт движения midpoint и двойное накопление zoomStep.
- Полная и сгруппированная проекции рассчитываются вместе в фоне. Zoom смешивает готовую пару и не запускает regroup/layout. Selection не меняет состав групп.
- Visual attention рассчитывается из screen-space: центр, площадь, focal point, недавнее взаимодействие, selection и landmarks. Окружение сохраняет минимальную видимость.
- Общий `ui/surfaces.ts`: стек поверхностей, backdrop, Escape, Back, поглощение pointer-событий и возврат фокуса. Сохранены проверки несохранённого редактора и busy.
- Layout учитывает площадь поддеревьев и подписей, расслабляет связи и устраняет контакты. Физика получает component/branch fields. После drag длина связи больше не становится постоянным rest length; topology bridge может преодолеть manual resistance. Pins остаются жёсткими.
- Render-state переведён на `$state.raw`, читаемость цветов кешируется, измерения подписей используют базовый размер, сохранение камеры перенесено на окончание жеста. Превью во время жеста используют готовое содержимое и transform.

- Последний полный unit-run: 128/133. Исправлены копирование результатов clearance и ожидания тестов, несовместимые с новым контрактом grouping/soft memory/compactness. Повторное выполнение ещё не выполнено; нужны проверка этих изменений и подтверждение качества композиции, а не только численных порогов.

## Что проверить при возобновлении

1. `npm run check`, `npm test` — проверить оставшиеся failures, особенно dynamics, cohesion, composition.
2. `npm run test:e2e -- tests/e2e/mobile-spatial.spec.ts` — получить новые JSON-профили renderP95/frame p95 для 100/500/1000. Визуально просмотреть screenshots; при необходимости продолжить профилирование.
3. Проверить живую незакреплённую карту: локальные children, bridge, drag ветви, pin/unpin и большие импорты. Профилирующий fixture использует resistance=8 для повторяемости gesture-замеров и не заменяет динамический сценарий.
4. Проверить nested transient surfaces, dirty editor, busy restore, Back/Forward и переход меню → настройки: общий history manager требует отдельного browser regression.
5. Финальный review async layout/projection lifecycle, соответствия hit-testing видимому LOD и сохранения данных; regression offline/Pages. До этого задача не завершена.
